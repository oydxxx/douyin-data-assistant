# 抖音数据助手

你不需要懂代码，也不用复制粘贴一堆数据。

## 最新更新：v0.7.0（可验证交接协议）

这次更新先把采集和导入之间的契约固定下来：

- 扩展不再把普通统计接口当成关联词数据采集。
- 交接文件包含版本、批次 ID、记录数和确定性协议。
- 导入飞书前，Agent 必须识别相同的主关键词、关联词、类型、时间范围和地域。
- 已有相同数据时更新原记录，不再反复新增。
- 以前已存在的重复项可以对 Agent 说“清理重复数据”后统一处理。

完整历史见 [更新日志](./CHANGELOG.md)。已安装旧版的用户，只需在浏览器扩展管理页点击一次“刷新”。

**抖音数据助手**会在你已登录的抖音数据页面中自动收集你正在查看的数据；当你对 Codex 说一句“导入飞书”，Agent 就会把这些数据整理后写入你的飞书多维表格。

```text
你正常搜索抖音数据 → 抖音数据助手自动采集 → Codex 整理 → 飞书多维表格
```

## 它能帮你省掉什么

- 不必手动复制关键词、关联词或指标。
- 不必填写飞书 App ID、密钥或表格 Token。
- 不必导出文件、上传文件或反复切换页面。
- 采集和导入分开：扩展只负责收集数据；只有你明确说“导入飞书”后，Agent 才会写入飞书。

数据不经过自建服务器。扩展只在你的浏览器本地保存数据，并交给同一台电脑上的 Agent 处理。

从 v0.7 起，扩展只保留符合“关联词 + 指标”结构的数据；单批最多保留 200 条，达到上限会在扩展中提示，不再静默丢弃。Agent 导入时必须使用版本化交接文件和业务键去重。

## 适合谁

适合想把抖音数据沉淀到飞书、做选题研究、账号分析或内容获客的人。即使你从没装过扩展，也可以照着下面操作。

## 安装（给人看）

### 第一步：下载项目

在本仓库页面点击绿色的 **Code**，再点 **Download ZIP**。解压后，请记住 `douyin-data-assistant` 文件夹的位置。

### 第二步：安装浏览器扩展

1. 在 Chrome 地址栏打开 `chrome://extensions`；如果你用 Edge，打开 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择刚才解压得到的 `douyin-data-assistant` 文件夹。
5. 浏览器工具栏出现“抖音数据助手”即表示完成。

首次进入抖音数据页面时，浏览器会提示该页面正在被调试。这是扩展读取当前页面返回数据的必要提示，不需要填写账号或密码。

### 第三步：把 Agent 装好

把仓库中的 [`AGENT_INSTALL.md`](./AGENT_INSTALL.md) 直接发给 Codex，并对它说：

> 请按这份安装说明帮我完成抖音数据助手的 Agent 配置。

Agent 会安装导入能力、检查飞书 CLI 是否可用，并帮你确认未来要写入哪张飞书多维表格。

## 日常怎么用

1. 打开并登录抖音数据页面。
2. 像平时一样搜索、筛选或翻页。
3. 回到 Codex，说：**“导入飞书。”**

第一次导入时，Agent 可能会问你要写入哪张飞书多维表格；选一次后，之后只需要说“导入飞书”。

## 常见问题

### 我看到“等待监听”怎么办？

确认你正在打开已登录的抖音数据页面。仍未开始时，在扩展管理页对“抖音数据助手”点一次刷新，再回到抖音页面。

### 已经安装过旧版扩展，怎样获得防重复更新？

在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，找到“抖音数据助手”后点击一次刷新。回到抖音页面重新搜索即可；旧版本地采集数据不会再交给 Agent 导入。

### 为什么 Agent 不直接写飞书？

写入飞书会改变你的数据，所以必须由你明确说“导入飞书”来触发。这样既简单，也能避免误写。

### 发现以前有重复数据怎么办？

对 Codex 说：**“清理重复数据。”** 它会先按“主关键词、关联词、类型、时间范围、地域”找出重复项，保留指标更完整的一条，再删除其余记录并告诉你处理结果。

### 它会抓取我所有的浏览记录吗？

不会。扩展只监听页面 `creator.douyin.com` 返回的 XHR / Fetch 数据，不读取密码、Cookie、聊天记录或其他网页。

## 项目结构

```text
.
├── manifest.json                # 浏览器扩展配置
├── background.js                # 自动监听页面与本机交接
├── popup.*                      # 扩展状态界面
├── offscreen.*                  # 本机交接文件下载
├── protocol.mjs                 # 版本化交接与业务键协议
├── AGENT_INSTALL.md             # 交给 Agent 的安装说明
└── douyin-import-feishu/        # Codex 导入 Skill
```
